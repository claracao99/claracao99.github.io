<CaseSection label="Approach">

Pickup and destination sat in two separate fields, so nothing showed they
made one trip, or which way it went.

I joined them into one connected field: pickup, stops and destination on a
single route.

I reused the route styling from the order flow rather than inventing new
icons, so a route now reads the same from search to receipt.

</CaseSection>

<CaseSection label="Results">

A no-harm A/B test kept orders and GMV neutral, with every trend positive.
Session-to-finish rose 0.14%, though it isn’t counted, since riders joined the
test before reaching search. The new search bar has been live for all riders
since October 2026.
